Marfeyx Instagram Interpreter

Privacy Policy

Last updated: September 7, 2026

Back to app Public issue tracker

Collected Data

The app reads Instagram export ZIP files locally in your browser. Messages, participants, timestamps, reactions, shared links, and media previews are processed on your device to render the viewer and statistics.

The exported ZIP, parsed chat contents, and generated preview object URLs are not intentionally uploaded to this site by the frontend.

Storage and Uploads

Instagram ZIP files are parsed locally. This version does not store Instagram exports or uploaded media in server storage. If storage is added later, this policy should be updated before launch to describe what is stored, why it is stored, and how deletion works.

Purpose of Processing

  • Render Instagram exports in a readable interface on the user's device.
  • Calculate local chat statistics, search results, and filtering results.

Retention

Locally parsed chat data remains in browser memory during the active session and is cleared when the page is refreshed, closed, or a new file replaces it.

User Rights

Depending on your location, you may have rights to access, correct, export, restrict, object to, or delete personal data. For requests, contact the site operator.

Contact

Privacy questions can be submitted through the public issue tracker. Do not include message contents, exported files, or other personal data in a public issue.
